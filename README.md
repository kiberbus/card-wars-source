# Карточные войны: исходный код

Код фанатского порта настольной игры Card Wars из мультсериала «Время приключений». Игра сделана на Godot 4. Скачать готовую игру можно на странице [kiberbus/card-wars](https://github.com/kiberbus/card-wars).

Здесь лежит код игры: правила и карты, ИИ, интерфейс, Бесконечный поезд, клиент игры по сети и тесты. Картинок, музыки и звуков здесь нет. Они принадлежат авторам мультсериала и настольной игры, и выкладывать их мы не можем. Игра берёт их из установленной копии.

Обсуждение и вопросы в нашем [Discord](https://discord.gg/hDNwrYtvy).

## Как запустить

1. Скачай [Godot 4.7](https://godotengine.org/download), обычную версию без .NET.
2. Установи саму игру со страницы [kiberbus/card-wars](https://github.com/kiberbus/card-wars) и запусти её один раз, чтобы она скачала последнее обновление.
3. Из папки проекта запусти `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\make_dev_assets_pack.ps1`. Команда соберёт локальный пакет только с картинками, звуками и импортированными ресурсами; сцены и скрипты из установленной игры в него не попадут.
4. Открой в Godot файл `project.godot` из этой папки и запусти проект (F5). Удалять или переносить `CardWars.pck` не нужно.

Для запуска из редактора команда создаёт `dev_assets_clean.pck` в папке данных Godot проекта. В него попадают только игровые ресурсы; скомпилированные сцены и скрипты из установленной игры не загружаются поверх исходников проекта. Исходный `CardWars.pck` не изменяется.

Если игра установлена не в стандартную папку, путь к пакету можно передать явно:

```
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\make_dev_assets_pack.ps1 -GamePack "D:\путь\CardWars.pck"
```

Этот шаг влияет на запуск проекта из редактора (F5), но не изменяет установленный `CardWars.exe`. Для обновления установленной игры нужен отдельный пакет обновления.

Если нужно найти исходный пакет вручную:

- на Windows в папке установщика: `%LOCALAPPDATA%\Programs\CardWars\CardWars.pck`;
- на macOS в `CardWars.app` из папки «Программы»;
- если игра стоит в другом месте (zip-версия, Linux), создай рядом с `project.godot` файл `game_path.txt` и напиши в нём путь к `CardWars.pck` или к папке с ним.

Команда выше также берёт обновления, которые скачала установленная игра. Если в коде появились новые карты, а игра ещё не обновлена, у таких карт не будет картинок.

В разделе «Обучение» можно открыть правила и выбрать для них русский, английский или корейский язык. Правила также доступны из меню паузы на русском. Перед базовым обучением отдельно выбирается язык подсказок и диалогов. При выборе английского или корейского рядом с превью карты показывается перевод её свойства для карт учебных колод; карты без свойства не получают отдельную панель. Названия карт, включая названия в свойствах, изображения карт и остальной интерфейс остаются на русском. Для корейского текста нужен системный шрифт с поддержкой корейского языка.

Продвинутое обучение предлагает короткие практические задания: огонь, мороз, «Хрум» и переворот земель. Язык подсказок и переводов свойств карт в заданиях выбирается перед началом; сами карты и игровой интерфейс остаются на русском.

## Тесты

Тесты запускаются без окна:

```
godot --headless --path . -s res://tests/rules_test.gd
godot --headless --path . -s res://tests/cards_test.gd
godot --headless --path . -s res://tests/deck_rules_test.gd
godot --headless --path . -s res://tests/hooks_test.gd
godot --headless --path . -s res://tests/tutorial_menu_test.gd
godot --headless --path . -s res://tests/tutorial_language_test.gd
godot --headless --path . -s res://tests/basic_tutorial_setup_test.gd
godot --headless --path . -s res://tests/basic_tutorial_flow_test.gd
godot --headless --path . -s res://tests/advanced_tutorial_test.gd
godot --headless --path . -s res://tests/sim.gd -- 300 1
```

Все должны проходить без ошибок. Если правишь правила или карты, добавь проверку в `tests/cards_test.gd`.

## Где что лежит

- `scripts/core`: правила, движок партии, карты и их способности, реплеи.
- `scripts/ai`: ИИ соперника.
- `scripts/train`: Бесконечный поезд.
- `scripts/ui`: экраны, стол, конструктор колод, раскладка для телефонов.
- `scripts/net`: игра по сети, аккаунты, обновления.
- `data/cards.json`: все карты. `data/ai_policy*.json`: веса ИИ.
- `rl_training`: обучение ИИ на Python.
- `tests`: тесты.

Сервера (комнаты по сети, рейтинг, турнирный бот) в этом репозитории нет. Игра из редактора подключается к тому же серверу, что и обычная.

## Как предложить правку

Сделай форк, внеси правку в отдельной ветке и открой pull request. Опиши, что поменялось и как это проверить. Интерфейс должен работать и на телефоне: проверь его в альбомной ориентации на маленьком экране.
